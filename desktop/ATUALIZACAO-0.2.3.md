# GrepoPilot Desktop 0.2.3

- Integra o motor remoto GrepoPilot 1.0.4 (ramo grepopilot-updates).
- Esquiva: prioriza aliados da mesma ilha, permite qualquer cidade da ilha ou cidades próprias.
- Mostra classificações de ataque, motivos que impedem envios e apoios pendentes.
- Pode informar ID da cidade, validado contra cidades identificadas na ilha.
- Botão para ativar esquiva real na HUD, sem recarregamento periódico.
- Preserva as correções do recrutamento real e os motivos de espera de tropas.

Teste no Windows: execute INICIAR-WINDOWS.bat. Para criar o instalador: CRIAR-INSTALADOR-WINDOWS.bat.
O catálogo de outros jogadores vem dos dados públicos do próprio mundo; enquanto não carregado, são usados dados das cidades já conhecidas no cliente.
